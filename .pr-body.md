**New presentation**
- **Info button** (`mdi:information-outline`, 20 px, `--secondary-text-color`). It sits right after the main temperature. With `show_main: false` it moves next to the chart's mode-toggle button, or into the toggle's spot if `forecast.show_mode_toggle: false`. With neither a live block nor a chart there is no button.
- The button switches to `--primary-color` when any shown live value fell back to the weather entity or a station sensor is stale.
- It is built with `_activatable`: role button, Enter/Space, `aria-haspopup="dialog"`. Its accessible name "Data sources" comes from visually hidden text inside the button, not an `aria-label` attribute. This leaves `_activatable`'s output for every other row byte-identical; the existing template-string tests depend on that.
- **Popup** (`src/sources-popup.ts`) follows the zero-degree popup's pattern: backdrop, panel, title and ×, Escape and backdrop click close it, Tab stays inside, focus goes back to the button, and teardown closes it. It is a separate module, so `zero-degree-popup.ts` is untouched.
  - **Live values / Aktuelle Werte:** one line per shown value in card order, as `label value · source · entity id`. Weather-service and stale lines use the accent colour. A stale line ends with "last value, unavailable since HH:MM", taken from `last_changed` in the card's time zone. Sun and moon show "Calculated from the location". Next rain is listed with the source its own tooltip already names. Zero-degree rows are left out. Tapping a line with an entity closes the popup and fires `hass-more-info`.
  - **Chart / Diagramm:** carsmie's legend items as a list with swatches (solid, dashed, bar). The section is hidden when no chart is shown.
- **Wording:** the source is "Weather service" / "Wetterdienst". Dashed lines are "Forecast" / "Prognose", so the chart section reads "Forecast: Weather service" and never "Forecast: Forecast".
- **Editor:** a toggle "Info button: data sources" / "Info-Knopf: Datenquellen" with a one-line hint, at the end of the live-panel section.
- **Texts:** new strings in `en.ts` and `de.ts`; other locales fall back to English (#415 is not merged). Popup line labels reuse the editor's sensor-field names, which every locale already translates.
- **Off = unchanged:** without `show_sources` the button and the `data-wsc-token` line markers are not rendered, and all existing templates are byte-identical.
- Docs: `docs/CONFIGURATION.md` (`show_sources`, `source_labels`), CHANGELOG `### Added`, ADR-0031, and the rebuilt `dist/`.

## Points to decide

- **Wind-direction source:** without the separate wind fix, the card still shows the raw state of a wired direction sensor even when it is unavailable. The recorded source copies that behaviour (station or stale), so the popup always names the source of the number actually shown. Once the wind fix lands, this should switch to carsmie's numeric-state rule.
- **Precipitation source:** names `sensors.precipitation_rate` when one is wired (#253), because that is the entity the row shows.
- **Duplicated formatting:** the popup's value strings are built by `_sourceValueText`, a second formatter next to the row helpers. Sun and moon read the rendered line text instead. The ADR lists this under Cons.
- **Shared popup shell:** not extracted. That would have meant touching the zero-degree popup, which the issue asked to keep as it is.
